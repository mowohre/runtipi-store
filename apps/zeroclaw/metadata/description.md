# ZeroClaw - Personal AI Assistant

ZeroClaw is a fast, lightweight, and fully autonomous AI personal assistant that runs on your own hardware. Built in 100% Rust for minimal resource usage (<5MB RAM).

## Features

- **Multi-channel support**: WhatsApp, Telegram, Slack, Discord, Signal, iMessage, Matrix, IRC, Email, and more
- **Web dashboard**: Real-time chat, memory browser, config editor
- **Hardware peripherals**: ESP32, STM32, Arduino, Raspberry Pi GPIO support
- **70+ tools**: Shell, file I/O, browser, git, web fetch/search, MCP integrations
- **Secure by design**: Pairing, sandboxing, workspace isolation, allowlists

## Usage

After installation, access the ZeroClaw gateway at `http://<your-server>:42617` (or custom port).

Configure your provider and API key during setup. The default provider is OpenRouter.
